# Contributing

Bug reports are welcome. We do not take pull requests yet, because the contributor agreements are not ready. This repository is a one-way export of a private one, so a fork can follow it but nothing merges back.

## Build and check

You need Node and pnpm. The Mac and iOS apps also need Xcode.

```sh
pnpm install
pnpm verify:fast
```

`pnpm verify:fast` runs the checks.

## Names

The Starlings and Envisioning names and marks are not part of the licence. See [NOTICE](NOTICE). A fork needs its own name.

## Security

Do not report a vulnerability in an issue. See [SECURITY.md](SECURITY.md).
