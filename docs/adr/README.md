# ADRs

Architecture decision records taken from 2026-09-10 on.

This repo's **existing** decisions are not here — they are prose documents under
`docs/`, listed in [../agents/CONTEXT.md](../agents/CONTEXT.md#where-decisions-already-live).
`docs/WORK_SURFACE.md` holds the open ones, `docs/BOARD.md` and
`docs/CORE_REGISTRY.md` hold locked registers. Read those before assuming a
decision is unmade because there is no ADR for it.

Numbered `NNNN-kebab-title.md`, created by `/domain-modeling` when a decision
actually lands.
